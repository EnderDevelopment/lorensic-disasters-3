# Lorensic Natural Disasters

Lorensic Natural Disasters is a Minecraft plugin that introduces realistic natural disasters into your world. This plugin features a variety of natural disasters such as tornados, hurricanes, lakebursts, tsunamis, and flashfloods. Each disaster is designed to be as realistic as possible, with features like rain puddles, rain particles, water vapor particles, and realistic water gravity systems. The plugin also includes enhanced features and cats, as well as whirlpools of varying sizes.

## Install

1. Download the plugin JAR file from the releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server.

## Use

1. To spawn a natural disaster, use the command `/disaster <type> <size> <location>`.
   - `<type>` can be tornado, hurricane, lakeburst, tsunami, or flashflood.
   - `<size>` can be small, medium, or large.
   - `<location>` can be a player name or coordinates (x y z).

2. Example commands:
   - `/disaster tornado medium @p` - Spawns a medium-sized tornado at the player's location.
   - `/disaster hurricane large 100 64 200` - Spawns a large hurricane at the specified coordinates.
